ConectaPyme: Cronograma de actividades

1.Objetivo

Organizar las actividades necesarias para desarrollar el proyecto ConectaPyme y establecer un tiempo aproximado para completar cada etapa.

2.Planificación

Semana 1: Análisis del problema

Actividades:

Identificar el problema de comunicación de la empresa.

Seleccionar el sistema que se va a desarrollar.

Definir los objetivos y el alcance.

Responsable: Jose.

Resultado esperado: documento de contexto del proyecto.

Semana 2: Organización del equipo

Actividades:

Definir los actores del sistema.

Distribuir las responsabilidades.

Elaborar el contrato de comunicación.

Responsable: Todo el equipo.

Resultado esperado: documentos de actores y contrato de comunicación.

Semana 3: Organización del repositorio

Actividades:

Crear y organizar el repositorio de GitHub.

Preparar el README y la licencia.

Registrar las tareas pendientes.

Responsable: Jose y todo el equipo.

Resultado esperado: repositorio organizado y documentación inicial.

Semana 4: Diseño del sistema

Actividades:

Identificar las clases principales.

Definir atributos y métodos.

Establecer las relaciones entre las clases.

Preparar el diagrama UML.

Responsable: Pedro.

Resultado esperado: diagrama UML del sistema.

Semana 5: Desarrollo inicial

Actividades:

Organizar los archivos del proyecto en Go.

Crear las estructuras principales.

Desarrollar las primeras operaciones del servidor.

Responsable: Dehivid.

Resultado esperado: primera versión del código.

Semana 6: Pruebas y correcciones

Actividades:

Ejecutar pruebas del código implementado.

Identificar errores.

Corregir los problemas encontrados.

Revisar el funcionamiento del servidor.

Responsable: Dehivid e Pedro.

Resultado esperado: código revisado y resultados de pruebas.

Semana 7: Revisión y presentación

Actividades:

Revisar los documentos.

Comprobar la organización del repositorio.

Preparar y grabar el video.

Revisar la entrega final.

Responsable: Todo el equipo.

Resultado esperado: proyecto organizado y listo para presentar.

3.Seguimiento

El grupo revisará semanalmente las actividades realizadas y las tareas pendientes.

Si alguna actividad se retrasa, se informará al equipo para reorganizar el trabajo y establecer una nueva fecha.

4.Observación

Este cronograma es una planificación inicial. Las fechas y los responsables podrán modificarse de acuerdo con el avance real del proyecto y las indicaciones del docente.
